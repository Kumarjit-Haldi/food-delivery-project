# FoodNest 🍔

FoodNest is a smart online food ordering website built with the MERN Stack.

## Features
- User Login & OTP Verification
- Food Search & Cart
- Online Payment
- Order Tracking
- Review & Rating
- Notifications
- AI Food Recommendation
- Admin Dashboard
- Demand Prediction
- Real-time Updates

## Technologies
React.js, Node.js, Express.js, MongoDB, Tailwind CSS, Groq AI, Socket.io
